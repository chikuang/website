# Customized Avicenna theme

This is the locally maintained theme for Chi-Kuang Yeh’s Hugo/blogdown website.
Use the [website README](../../README.md) for the current build and editing workflow.
Site-level `layouts/` override some of the theme templates.

The old upstream installation tutorial, sample configuration and screenshot link
have been removed because they do not describe this customized site.
