# Optimal-design illustrations

Created with the built-in `image_gen` tool for the optimal regression design tutorial, 2026-09-26. The selected assets use the user's requested cute, pastel, hand-drawn style. These are conceptual illustrations, not data or measured results; the five numerical plots remain generated by R.

## Saved website assets

- `static/resources/opt-design-illustrations/applications-cute.jpg` — application overview.
- `static/resources/opt-design-illustrations/workflow-cute.jpg` — question → model → design → experiment → check, with an update loop to the model.
- `static/resources/opt-design-illustrations/multiobjective-cute.jpg` — one experiment budget and two precision goals.

The generated PNG originals remain in the local Codex generated-images directory. Website copies are JPEGs encoded at quality 85 with their original dimensions. No content was changed during conversion.

## Prompt set

Each asset was generated separately and then edited with the same built-in tool to apply the requested cute style. The generation prompt and final editing prompt follow.

### applications

Generation prompt:

```text
Use case: scientific-educational. Create an original editorial illustration for an English academic tutorial on optimal experimental design. Style: sophisticated cut-paper and lightly textured 3D scientific editorial art, precise clean silhouettes, subtle depth and soft shadows, warm ivory background, navy #18283B, academic blue #155DA0 and restrained burnt orange #B65327 accents matching the existing article plots. Visually engaging but scholarly. Large clear forms that remain readable on a phone. No brand marks, watermark, decorative formulas, percentages, claims of empirical improvement, fake data plots, or extra text.
Asset: landscape website illustration, approximately 2:1. Show three equally sized integrated laboratory vignettes across a single canvas, with generous separation. LEFT: calibration, reference-solution vials with differing blue liquid levels beside a benchtop optical measurement instrument; a few carefully chosen vials are emphasized in orange. CENTER: concentration-response study, a pipette poised over a microplate with a progression of blue liquid concentrations; one small unlabelled compound-model silhouette, no chemistry formulas. RIGHT: prevalence survey using pooled specimens, several capped specimen tubes connected by a subtle schematic grouping bracket to a larger pooled-sample tube beside an assay reader, no mixing arrows back to individuals. Communicate that deciding which measurements to collect matters when assays, samples, and time are limited. Include ONLY these large short captions aligned with the three vignettes: "Calibrate instruments", "Learn response curves", "Estimate prevalence". No top title and no numerical results.
```
