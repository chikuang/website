# Chi-Kuang Yeh’s website

Personal academic website built with RStudio, blogdown, Hugo, and the customized
Avicenna theme. Live site: [chikuang.github.io](https://chikuang.github.io/).

## Workflow

Open `website.Rproj` in RStudio, then run:

```r
blogdown::serve_site()  # Preview while editing
blogdown::build_site() # Generate the GitHub Pages output
```

Alternatively, run `hugo` from this folder. Output goes to the separate
`../chikuang.github.io/` repository. Commit source changes here and generated
files there when publishing. Avoid `hugo --cleanDestinationDir`: the output
repository also contains course materials and CVs maintained separately.

## Source files

- `config.toml`: profile, affiliations, introduction, research interests,
  institution logos, publications, courses, and group members.
- `content/`: page metadata and resource posts. Keep both `.Rmd` originals
  and their `.html` renderings; Hugo uses the HTML generated by blogdown.
- `layouts/` and `themes/avicenna/`: templates and theme styles.
- `static/`: images, favicons, resource CSS, and `.nojekyll`.
- `scripts/`: optional R Markdown setup and processing helpers, run from
  this project folder, e.g. `Rscript scripts/process_rmd.R path/to/post.Rmd`.
- `docs/`: [resource guide](docs/resources.md) and [logo sources](docs/logo-sources.md).

## Display settings

Home, Publication, Software, Teaching, Group, and Resource share one page frame.
The navigation switches embedded content panels without reloading the page;
links such as `/#publications` can be bookmarked. Existing section URLs still
work, including without JavaScript. Resource articles retain their own URLs
and use the same profile and navigation. Arrow keys, Home, and End navigate
the tabs; browser back and forward restore the selected panel.

Section templates live in `layouts/partials/sections/`; shared typography and
spacing live in `static/css/sections.css`. Publication and Software use the
same contributor note from `params.publications_note` in `config.toml`.

Institution logos use transparent SVGs with light and dark variants. A group
with `collapsible = true` starts collapsed; its member count is automatic.

The footer shows the latest local modification date among `config.toml`,
`content/`, `layouts/`, `static/`, and the theme’s layouts and static assets.
Saving a source file and rebuilding updates it; rebuilding alone does not.
A fresh checkout or file copy may reset these timestamps. The copyright end
year updates automatically using two digits.

The footer's **Total views** uses [Busuanzi's cumulative site PV count](https://ibruce.info/2015/04/04/busuanzi/).
Its shared service persists the total across visitors, pages, and site rebuilds.
It includes repeat visits: each page load, change of embedded section, and
restoration from the browser's back/forward cache records one view. Selecting
the already active section does not record another view. The direct JSONP
request uses the same endpoint and referrer policy as Busuanzi's official
client, preserving any PV history already recorded by the previous UV widget.

Counting runs only on the hostname configured in `baseurl`, without a port.
Local previews display `Total views: Preview` and send no counting requests.
The public site shows a loading state, then the server's total. On a service
error or a 15-second timeout it shows `Unavailable`, or retains the last fetched
total with an explanatory tooltip. It does not invent counts or retry failed
increments, which could count the same view twice.

This is the total of **recorded views**, not a recoverable history since 2016.
Visits before tracking was installed cannot be reconstructed without a prior
analytics record. JavaScript blocking, network failures, and pages without this
shared footer (such as separately maintained course sites) are not counted.

Hugo 0.162+ requires explicitly allowing the local HTML generated by blogdown;
`config.toml` keeps Org content disabled. Build caches, RStudio session state,
and redundant `public/` output are ignored by Git.
